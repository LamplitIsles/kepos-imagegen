# Kepos Image Generation for Pi

Install it with:

```sh
pi install npm:@lamplitisles/pi-imagegen
```

Use `/kepos-image-settings` to view or change the Kepos bridge address. The
`kepos_image_generate` tool generates a PNG when `images` is omitted, or edits one
through five PNG, JPEG, GIF, or WebP files named relative to Pi's current working
directory. Kepos handles authentication; this extension neither reads nor stores
credentials.
